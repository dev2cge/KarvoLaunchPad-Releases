# Support

For reproducible bugs, open a bug report here. Include launcher/client version, Minecraft version, operating system, steps and expected behaviour. For account, purchase or refund enquiries use the support route on https://karvobot.uk/; never post transaction or account information in public issues.

Before attaching logs, remove session tokens, email addresses, chat, private server addresses, local usernames and filesystem paths. Never upload a launcher account file, .env file, Microsoft token, certificate/private key or complete user-data folder. Public issues are visible to everyone.

For recovery, restart the launcher, check the official website for availability and use the current official installer if necessary. Do not delete your Minecraft worlds or account data as a troubleshooting shortcut.

Response times are not guaranteed. This repository is for Karvo issues, not moderation appeals for unrelated servers.
