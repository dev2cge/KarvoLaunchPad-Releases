# Security reporting

Do not report exploitable vulnerabilities, account tokens or private customer data in a public issue. Use GitHub's private vulnerability reporting when available: Security → Report a vulnerability. If that option is unavailable, use the private support route on https://karvobot.uk/ and request a secure reporting channel before sending sensitive details.

Only current supported releases receive fixes. Updates and hashes are published through official Karvo channels. Self-signing and checksum publication do not guarantee malware-free software or remove operating-system warnings.
